# Contributing to awesome-medical-robustness

PRs welcome! This list is curated, not comprehensive — every entry should earn its place.

## Rules

1. **On-topic**: robustness of medical AI, broadly construed — benchmarks, adaptation, uncertainty/calibration, contamination/integrity, distribution shift, adversarial robustness, deployment monitoring.
2. **Quality bar**: actively maintained, or field-defining (a paper/tool everyone cites). No abandoned preprints, no paywalled-only resources, no marketing pages.
3. **One-line description**: say what it is and why a robustness researcher would care. No hype adjectives ("best", "SOTA" without a source).
4. **Working link**: verify the link resolves before submitting. Prefer the canonical URL (repo root, arXiv abstract page).
5. **Alphabetical within sections** (case-insensitive), except where a logical ordering reads better (papers chronologically is fine).
6. **No duplicates**: check the whole list, including his own repos — they belong here too, but only where they genuinely fit.

## Format

```markdown
- [Name](https://link) — One-line description of what it does and why it matters.
```

## Pull request checklist

- [ ] Entry follows the format above
- [ ] Link verified working
- [ ] Placed in the right section, alphabetical order kept
- [ ] Description is factual and concise

## Suggesting removals

If a project is dead (archived, 2+ years unmaintained, superseded), open a PR removing it with a one-line reason. Curation means pruning too.
